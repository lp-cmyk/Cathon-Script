# Code of Conduct — Cathon‑Script

## Our Pledge
We as members, contributors, and leaders pledge to make participation in the Cathon‑Script project a respectful, inclusive, and welcoming experience for everyone, regardless of background, skill level, experience, or identity.

We commit to act and interact in ways that contribute to an open, friendly, and healthy community around this self‑developed programming language.

## Our Standards
Examples of positive behavior include:
- Being respectful and polite to other community members
- Using constructive and kind language
- Accepting feedback gracefully
- Focusing on what is best for the project and its lightweight, cross‑platform design
- Respecting the original design and architecture of Cathon‑Script

Unacceptable behavior:
- Harassment, insults, personal attacks, or offensive comments
- Spam, irrelevant messages, or disruptive content
- Attempts to reverse‑engineer, steal or misappropriate the original language design
- Publishing sensitive information without permission
- Any behavior that violates the project’s security rules

## Enforcement
Project maintainers are responsible for enforcing this code of conduct.
They may remove, edit, or reject contributions, comments, issues or pull requests that violate these standards.

## Scope
This Code of Conduct applies to all project spaces including GitHub issues, pull requests, discussions, and any public communication related to Cathon‑Script.
