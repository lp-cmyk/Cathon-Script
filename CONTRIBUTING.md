# Contributing to Cathon‑Script

First of all, thank you for your interest in contributing to **Cathon‑Script (C&)** — the ultra‑lightweight self‑developed programming language designed for web, mobile and cross‑platform environments.

We welcome all forms of contributions including bug reports, feature suggestions, documentation improvements, code optimizations, syntax extension and ecosystem building.

## About the Project
Cathon‑Script is a **fully original architecture personal‑developed language**.
Core design, syntax specification, browser embedded system, compilation command rules and ultra‑small volume optimization are all original works.
Some underlying implementation codes are assisted by AI and manually audited.

## How to Contribute

### 1. Report Bugs
- Open an issue with clear title and detailed reproduction steps
- Attach relevant error logs, code snippets or screenshots
- Mark issue with label `bug`

### 2. Suggest Features
- Open an issue with label `enhancement`
- Describe your idea, use scenario and expected behavior
- Keep consistent with Cathon’s lightweight and cross‑platform design philosophy

### 3. Code Contribution
1. Fork this repository
2. Create your feature branch: `git checkout -b feature/your-feature-name`
3. Commit your changes: `git commit -m "feat: add xxx function"`
4. Push to your fork: `git push origin feature/your-feature-name`
5. Create a Pull Request to the main branch

### 4. Documentation Improvement
- Fix typos, optimize README, CLAUDE.md, SECURITY.md
- Add usage examples, syntax tutorials, web demo guides
- Translate or supplement multi‑language documents

## Code Style Rules
- Keep code lightweight and concise, consistent with the 99.9KB design goal
- Maintain existing syntax and command system (`car` compile command, `<car>` HTML tags)
- Avoid introducing heavy third‑party dependencies
- Ensure cross‑platform compatibility (Python / WASM / Android App / HTML)

## Security Notice
- Do NOT submit sensitive information, private keys, or hard‑coded secrets
- For security vulnerabilities, please refer to [SECURITY.md](./SECURITY.md)
- Do not create public issues for serious security problems

## Contact & Communication
All core design rights belong to the original developer.
Contributors shall respect the original design specifications of Cathon‑Script.

Thank you again for helping build Cathon‑Script together!
